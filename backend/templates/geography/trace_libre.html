Dessiner une route

Clique sur la carte pour poser chaque point du chemin, dans l'ordre. Un point posé sur une route existante (accroché) devient une jonction : la route est coupée à cet endroit pour que les deux soient reliées.

Aucun point posé

  • Retour arr. / Z annuler le dernier point
  • Entrée enregistrer · Échap tout effacer

Nouveau village

Clique sur la carte à l'emplacement du village (tu peux ensuite glisser le repère). Le fokontany, la commune, le district et la région sont proposés d'après les contours ; corrige-les si besoin.

Aucune position choisie

  • ▬ réseau routier · □ fokontany · ● ton nouveau village
  • Après la création, la région, le district, la commune et le fokontany restent choisis pour enchaîner les villages.

Rechercher et éditer

Modifier le village

Glisse le repère rouge (ou clique sur la carte) pour déplacer le village.

Modifier la route

Glisse un sommet pour le déplacer · glisse (ou clique) un petit cercle entre deux sommets pour créer un nœud · clic droit sur un sommet pour le supprimer. Une extrémité lâchée sur un autre sommet du réseau s'y raccorde. ● = jonction partagée avec d'autres routes (elles suivent).

Clique sur un village (●) ou sur une route pour l'éditer ; zoome (niveau 12 ou plus) pour les voir.
