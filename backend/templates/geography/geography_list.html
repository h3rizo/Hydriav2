Mettre à jour les coordonnées GPS des villages

Format attendu du fichier Excel :

  • Colonne A : ID du village (UUID, obligatoire)
  • Colonne B : Nom du village (pour référence visuelle)
  • Colonne C : Latitude (ex: -18.9332847)
  • Colonne D : Longitude (ex: 47.5079055)
  • Colonne E : Altitude en mètres (optionnel)

La première ligne doit contenir les en-têtes.

Astuce : Exportez d'abord les villages via "Export Excel" → "Export Villages" pour obtenir les IDs.

Mettre à jour l'accessibilité des villages

Format attendu du fichier Excel :

  • Colonne A : ID du village (UUID, obligatoire)
  • Colonne B : Nom du village (pour référence visuelle)
  • Colonne C : Accessibilité (pied, moto, voiture, pirogue, goudron)
  • Colonne D : Distance depuis dernier point accessible (en km)

Valeurs acceptées pour accessibilité : pied, à pied, marche, moto, voiture, auto, véhicule, pirogue, bateau, goudron, route, bitume

La première ligne doit contenir les en-têtes.
