Comment importer ?

  1. Cliquez sur "Importer depuis Access"
  2. Sélectionnez 1, 2 ou 3 fichiers Access (.mdb ou .accdb)
  3. Donnez un nom à chaque fichier pour l'identifier
  4. Cliquez sur "Lancer l'import"

Note: Vous pouvez importer un seul fichier, deux fichiers ou trois fichiers selon vos besoins. Seul le premier fichier est obligatoire.

Mise à jour: Si vous réimportez les mêmes fichiers (même nom), les données existantes seront automatiquement mises à jour.

Import depuis Windows - Package Portable

Mode d'import LOCAL (Portable)

Cette méthode lit les fichiers Access directement depuis votre ordinateur Windows et envoie les données vers le serveur. Le package portable peut être utilisé sur n'importe quel ordinateur.

📦 Télécharger le Package Portable

Téléchargez le fichier ZIP contenant tous les fichiers nécessaires :

Télécharger Package_Import_DiameX_Portable.zip

Le package contient :

  • INSTALLER_IMPORT_DIAMEX.bat - Installation automatique
  • LANCER_IMPORT.bat - Lancement de l'import
  • LANCER_AGENT_DIAMEX.bat - Lancement de l'agent local
  • import_diamex_portable.py - Script Python
  • diamex_local_agent.py - Agent local (serveur)
  • config_import.ini - Configuration
  • README_IMPORT_DIAMEX.txt - Documentation complète

Import via agent local (boutons web)

1) Lancez LANCER_AGENT_DIAMEX.bat sur le PC
2) Cliquez sur "Tester connexion" puis "Importer via agent local"
3) Les scans .tif/.tiff seront convertis en PDF pour un affichage web plus lisible

Suivi en temps reel
📥 INSTALLATION (Première fois uniquement)
Étape 1 : Créer un dossier

Créer un nouveau dossier sur l'ordinateur, par exemple :

C:\ImportDiameX
Étape 2 : Copier les 5 fichiers

Copier les 5 fichiers du package dans ce nouveau dossier.

Étape 3 : Exécuter l'installation

Double-cliquer sur INSTALLER_IMPORT_DIAMEX.bat

Le script va automatiquement :

  • Vérifier que Python est installé
  • Installer les dépendances (pyodbc, requests, pillow)
  • Vérifier le driver Microsoft Access
Si Python n'est pas installé, télécharger depuis python.org et cocher "Add Python to PATH"
Étape 4 : Vérifier la configuration

Ouvrir config_import.ini avec le Bloc-notes et vérifier :

DJANGO_URL = https://compta.hydria.mg

Cette URL doit pointer vers le serveur Django.

    • Employé : Sélectionner l'employé

🔧 DÉPANNAGE
❌ "Python n'est pas installé"

→ Télécharger Python depuis python.org

→ IMPORTANT : Cocher "Add Python to PATH" lors de l'installation

❌ "Driver Microsoft Access non détecté"

→ Si Microsoft Office installé : Le driver devrait être présent

→ Sinon, télécharger "Access Database Engine 2016 Redistributable"

→ Choisir 32-bit ou 64-bit selon votre version d'Office

❌ "Fichier introuvable"

→ Vérifier le chemin configuré dans Django

→ Vérifier que le fichier .accde existe à cet emplacement

❌ "Erreur réseau"

→ Vérifier la connexion internet

→ Vérifier que https://compta.hydria.mg est accessible

→ Augmenter le TIMEOUT dans config_import.ini
