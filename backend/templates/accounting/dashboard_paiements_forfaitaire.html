Code couleur du nom de l'ouvrage

La couleur du nom indique l'état d'encaissement du paiement forfaitaire de l'ouvrage : montant enregistré en comptabilité rapporté au montant « Paiement forfaitaire » attendu. Le badge de pourcentage affiché à côté du nom suit le même code. Seules les couleurs présentes dans le tableau ci-dessous (filtres et page en cours) sont listées.

Rouge — facture échue mais rien encaissé (0 %).
Jaune — partiellement encaissé (1 % à 99 %).
Vert — intégralement encaissé (100 %), ou aucune facture échue à ce jour : l'échéance n'est pas encore atteinte, le non-paiement est normal (prioritaire sur les autres couleurs).
Bleu — encaissé au-delà du forfait (> 100 % : avance ou trop-perçu).
Couleur normale — aucun paiement forfaitaire enregistré pour cet ouvrage : rien à recouvrer sur ce volet.
