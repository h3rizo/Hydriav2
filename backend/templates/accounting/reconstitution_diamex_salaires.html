Comment ça fonctionne ?

Le système cherche dans la table BaseDiameX en utilisant :

  • Salaire : Description contenant "Salaire_YYYY MM" + Detail avec surnom employé
  • IRSA : Description contenant "IRSA_YYYY MM" + Detail avec surnom
  • CNaPS : Description contenant "CNaPS_YYYY MM" + Detail avec surnom
  • FMFP : Description contenant "FMFP_YYYY MM" + Detail avec surnom
  • Mutuelle : Description contenant "OSIEF" ou "AMIT" + "YYYY MM" + Detail avec surnom
