Importer des réparations depuis Excel

Obligatoires : ID Ouvrage, Activité (nom exact), Date (JJ/MM/AAAA). Optionnelles : ID Point d'eau ou ID Équipement (un seul des deux), Composants (noms séparés par « ; », pris dans la liste du type de la cible), ID Désignation + Quantité/Prix unitaire (ajoute une ligne de détail), Description, ID Responsable, Validée (Oui/Non), Statut (en_cours/termine/annule/reporte). Les règles de l'activité (cible ou composants obligatoires) sont les mêmes que dans « Ajouter une réparation ». Le modèle contient un onglet de référence par entité (UUID + nom) : Ouvrages, Points d'eau et Équipements (avec leurs composants possibles), Composants possibles, Désignations, Employés autorisés, Activités, Statuts.
