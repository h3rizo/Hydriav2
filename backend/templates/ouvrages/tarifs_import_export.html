📤 Importer depuis Excel

Importer ou mettre à jour des tarifs volumétriques depuis un fichier Excel

📋 Format du fichier Excel

Colonnes requises :

  • ID Tarif : UUID du tarif (laisser vide pour créer un nouveau tarif)
  • Ouvrage : Nom exact de l'ouvrage (obligatoire)
  • Date Début : Format AAAA-MM-JJ (obligatoire)
  • Date Fin : Format AAAA-MM-JJ (optionnel)
  • Prix Abonnement : Prix en Ariary
  • Actif : Oui/Non
  • Tranche Supérieure (m³) : Volume maximum de la tranche
  • Tarif (Ar/m³) : Prix unitaire de la tranche
Un tarif peut avoir plusieurs tranches. Utilisez plusieurs lignes avec le même ID Tarif pour définir plusieurs tranches.
