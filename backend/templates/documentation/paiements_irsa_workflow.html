Workflow Paiements IRSA - Export DiameX

  • Documentation
  • Paiements IRSA

Vue d'ensemble

Le module de Paiements IRSA (Impôt sur les Revenus Salariaux et Assimilés) permet de calculer, générer et exporter automatiquement les paiements d'IRSA vers le système comptable DiameX.

  • Calcul automatique : Basé sur les grilles salariales et les barèmes IRSA en vigueur
  • Génération de factures Excel : Liste détaillée par employé avec totaux
  • Export DiameX automatique : Création de lignes comptables lors de l'impression
  • Workflow irréversible : Une fois imprimée, la facture ne peut plus être modifiée
  • Montants exacts : SANS arrondi (contrairement aux salaires)
DIFFÉRENCE CRITIQUE avec les Salaires : Les montants IRSA sont exportés SANS arrondi (montant exact), alors que les salaires sont arrondis au supérieur (100 Ar près).

Le marquage "Imprimée" déclenche automatiquement l'export vers DiameX. Cette action est irréversible et crée des lignes comptables en attente de validation.

Workflow détaillé en 5 étapes

stateDiagram-v2 [*] --> Brouillon : Création paiement Brouillon --> Validé : Validation Validé --> FactureGénérée : Génération Excel FactureGénérée --> Imprimée : Marquage + Export DiameX Imprimée --> Payé : Paiement effectif Payé --> [*] note right of Imprimée Export automatique: - Pour chaque employé - Création ligne DiameX - Montant EXACT (sans arrondi) - Statut: en_attente end note
Étape 1 : Création du paiement IRSA (Brouillon)

Accès : Plannings > Paie > Paiements IRSA > Nouveau Paiement

Informations requises :

  • Organisation : Entité concernée (ex: SOAKOJA)
  • Mois : Mois du paiement (1-12)
  • Année : Année du paiement
  • Date de paiement : Date prévue du paiement

Processus automatique :

  1. Le système récupère tous les salaires payés pour ce mois
  2. Pour chaque salaire, calcule l'IRSA selon le barème en vigueur
  3. Crée un PaiementIRSADetail pour chaque employé
  4. Calcule les totaux (brut, base imposable, IRSA)
  5. Sauvegarde avec statut "brouillon"
Étape 2 : Validation du paiement (Validé)

Action : Cliquer sur "Valider" dans le menu Actions

Vérifications à effectuer :

  • Nombre d'employés correct
  • Montants IRSA cohérents avec les salaires
  • Somme totale correspond aux attentes

Résultat :

  • Statut passe à "Validé"
  • Le bouton "Générer facture" devient disponible
  • Impossible de modifier les montants après validation
Étape 3 : Génération de la facture Excel

Action : Cliquer sur "Générer facture" dans Actions

Contenu du fichier Excel :

  • En-tête :
    • Organisation : Nom de l'organisation
    • Période : Mois/Année
    • Date de paiement : DD/MM/YYYY
  • Tableau :
    N° Nom Complet Salaire Brut Base Imposable IRSA
    Exemple de lignes...
  • Ligne de totaux : Sommes de chaque colonne

Résultat :

  • Fichier Excel téléchargé automatiquement
  • facture_generee = True
  • Date de génération enregistrée
  • Badge "Facture" passe à "Générée" (vert)
Étape 4 : Impression et export DiameX (Imprimée) - CRITICAL

Prérequis :

  • ✅ La facture doit avoir été générée (facture_generee = True)
  • ✅ La facture ne doit PAS avoir été déjà imprimée (facture_imprimee = False)

Étape manuelle :

  1. Ouvrir le fichier Excel téléchargé
  2. Imprimer la facture (2 exemplaires recommandés)

Action système :

  1. Retourner sur la page Paiements IRSA
  2. Cliquer sur "Marquer imprimée + Export" dans Actions
  3. Confirmer dans le popup d'avertissement

⚙️ Traitement automatique pour CHAQUE employé :

  1. Récupération de la chaîne de données :
    • PaiementIRSADetail → Salaire
    • Salaire → GrilleSalaire
    • GrilleSalaire → Contrat
    • Contrat → Employe
    • Employe → Poste
  2. Vérification du compte IRSA :
    • Si Poste.compte_irsa est NULL → Erreur
    • Erreur enregistrée mais traitement continue
  3. Création ligne DiameXTemporaire :
    • Description : _{préfixe_poste} {nom_complet}_IRSA_{année} {mois:02d}
    • Cat (compte_code) : Poste.compte_irsa.compte
    • Detail : Employe.surnom ou Employe.prenom
    • ACTIV : Employe.volet
    • Out (montant_out) : detail.montant_irsa (SANS arrondi)
    • Date_m : paiement.date_paiement
    • Info : 'Hydria IRSA'
    • Type : 'depense'
    • Statut : 'en_attente'

Mise à jour du paiement :

  • facture_imprimee = True
  • date_impression = now()
  • Badge "Imprimée" devient visible (vert)
  • Bouton "Marquer imprimée" disparaît

⚠️ ATTENTION : Cette action est IRRÉVERSIBLE

Étape 5 : Export vers DiameX et paiement

Consultation des lignes en attente :

  1. Accéder à : Comptabilité > DiameX Temporaire
  2. Filtrer par statut = "en_attente" et info = "Hydria IRSA"
  3. Vérifier les montants et comptes

Export vers DiameX (manuel actuellement) :

  1. Exporter les lignes en Excel
  2. Importer dans le système DiameX externe
  3. Marquer les lignes comme "exporté" dans Hydria

Paiement effectif :

  • Effectuer le paiement IRSA aux impôts
  • Mettre à jour le statut du paiement IRSA → "Payé"

Format d'export DiameX

Structure de la description

_{préfixe_poste} {nom_complet}_IRSA_{année} {mois:02d}

Exemples

Champs complets de la ligne DiameX

Champ Source Exemple Notes

statut Constante en_attente En attente d'export

Règles CRITICAL

⚠️ MONTANT SANS ARRONDI

Les montants IRSA sont exportés EXACTEMENT comme calculés, SANS arrondi.

Différence avec les salaires :

  • ❌ Salaires : Arrondis au supérieur (100 Ar près) avec math.ceil()
  • ✅ IRSA : Montant exact, pas d'arrondi

Exemple :

  • Montant IRSA calculé : 125,742.50 Ar
  • Export DiameX : 125742.50 Ar (exact)
  • Si c'était un salaire : 125,800.00 Ar (arrondi)

⚠️ IRRÉVERSIBLE APRÈS IMPRESSION

Une fois la facture marquée comme "Imprimée" :

  • ❌ Impossible de modifier les montants
  • ❌ Impossible d'annuler l'export DiameX
  • ❌ Impossible de supprimer les lignes DiameX générées
  • ✅ Seule solution : Modification manuelle en base de données (réservé aux admins)

⚠️ COMPTE IRSA OBLIGATOIRE

Chaque poste DOIT avoir un compte_irsa défini AVANT l'export.

En cas de compte manquant :

  • ✅ La facture est quand même marquée comme imprimée
  • ⚠️ Une erreur est enregistrée pour cet employé
  • ✅ Les autres employés sont exportés normalement
  • 📧 L'administrateur doit corriger le compte et relancer l'export manuellement

⚠️ FORMAT DESCRIPTION STRICT

La description DOIT commencer par un underscore _ pour cohérence avec les salaires.

Format : _{préfixe} {nom}_IRSA_{année} {mois}
Correct : _RESP Jean DUPONT_IRSA_2025 11
Incorrect : RESP Jean DUPONT_IRSA_2025 11 (manque le "_" initial)

FAQ - Questions Fréquentes

❓ Pourquoi les montants IRSA ne sont-ils pas arrondis contrairement aux salaires ?

Raison : Les déclarations IRSA aux impôts doivent être faites avec des montants exacts selon le barème fiscal. L'arrondi pourrait créer un écart avec le calcul officiel.

Pour les salaires : L'arrondi facilite le paiement en espèces et évite les fractions d'Ariary.

❓ Que faire si un employé n'a pas de compte IRSA défini ?

Symptôme : Message d'erreur lors de l'export : "{Nom employé}: Pas de compte IRSA défini pour le poste"

Solution :

  1. Accéder à : Administration > Organisation > Postes
  2. Trouver le poste concerné
  3. Cliquer sur "Modifier"
  4. Renseigner le champ "Compte IRSA" (ex: 6414)
  5. Sauvegarder
  6. Recréer le paiement IRSA pour ce mois (la facture précédente reste marquée imprimée)

⚠️ La facture imprimée ne peut pas être "dé-imprimée" pour correction

❓ Puis-je annuler une facture IRSA déjà imprimée ?

Réponse courte : NON, pas via l'interface.

Raison : Le marquage "Imprimée" a déjà déclenché la création de lignes comptables dans DiameX. Annuler créerait une incohérence.

Si vraiment nécessaire :

  1. Contacter l'administrateur système
  2. Intervention manuelle en base de données :
    • Mettre facture_imprimee = False
    • Supprimer les lignes DiameXTemporaire associées
  3. Recréer le paiement avec les bonnes données
❓ Comment exporter les lignes DiameX en attente vers le système comptable ?

Méthode actuelle (manuelle) :

  1. Accéder à : Comptabilité > DiameX Temporaire
  2. Filtrer par statut = "en_attente" et info = "Hydria IRSA"
  3. Cliquer sur "Exporter en Excel"
  4. Ouvrir le fichier Excel
  5. Importer dans le système DiameX externe
  6. Retourner sur Hydria
  7. Marquer les lignes comme "exporté"

⚙️ Amélioration future : Script automatique d'export direct vers DiameX (à développer)

❓ Quelle est la différence entre "facture_generee" et "facture_imprimee" ?
  • facture_generee : Le fichier Excel a été créé et téléchargé
    • Action : Génération automatique du fichier
    • Conséquence : Badge "Facture" → "Générée"
    • Réversible : Peut générer à nouveau
  • facture_imprimee : La facture a été physiquement imprimée ET l'export DiameX a été effectué
    • Action : Marquage manuel + export automatique
    • Conséquence : Création de lignes DiameX, badge "Imprimée"
    • Irréversible : Ne peut pas être annulé
❓ Combien de temps garder les factures IRSA ?

Obligation légale (Madagascar) : Conservation pendant 10 ans

Dans Hydria :

  • ✅ Les paiements IRSA restent accessibles indéfiniment
  • ✅ Les fichiers Excel générés doivent être archivés séparément
  • ✅ Les lignes DiameX conservent la traçabilité comptable

💡 Bonne pratique :

  • Créer un dossier Archives_IRSA/{Année}/
  • Sauvegarder tous les fichiers Excel mensuels
  • Backup automatique annuel recommandé
