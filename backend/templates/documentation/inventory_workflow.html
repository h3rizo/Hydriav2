Workflow Gestion des Stocks

  • Documentation

Vue d'ensemble

Le module de Gestion des Stocks permet de suivre l'ensemble des mouvements de matériel et fournitures à travers 5 workflows interconnectés :

  • Inventaire : Comptage physique périodique et rapprochement avec le stock théorique
  • Fiche de stock : Traçabilité complète de tous les mouvements (entrées/sorties/ajustements)
  • Commande : Calcul automatique des besoins basé sur les demandes et le stock actuel
  • Achat : Workflow complet du brouillon au paiement avec export DiameX automatique
  • Transfert : Déplacement de stock entre magasins avec validation à la réception

Diagramme général des workflows

Workflow 1 : Inventaire

L'inventaire permet de comparer le stock théorique (système) avec le stock physique réel et d'identifier les écarts (pertes, erreurs de saisie, vols).
flowchart TD A[Début Inventaire] --> B[Sélectionner Magasin] B --> C[Sélectionner Désignation] C --> D[Compter Stock Physique] D --> E{Stock Théorique = Stock Physique?} E -->|Oui| F[Marquer Rapproché] E -->|Non| G[Enregistrer Écart] G --> H[Ajustement Stock] H --> I[Créer Fiche Stock Type Inventaire] F --> J[Mettre à jour Date Inventaire] I --> J J --> K[Fin]
Étape 1 : Préparation de l'inventaire

Accès : Inventaire > État des Stocks

Actions :

  • Sélectionner la base/magasin à inventorier
  • Filtrer par type de désignation si besoin
  • Utiliser la recherche pour trouver un article spécifique
  • Consulter le stock théorique actuel
Étape 2 : Comptage physique

Actions :

  • Compter physiquement les articles dans le magasin
  • Noter la quantité réelle sur une feuille de comptage
  • Vérifier les unités de mesure (pièce, kg, mètre...)
  • Pour les articles de valeur, faire un double comptage
Étape 3 : Saisie et ajustement

Page : Inventaire > État des Stocks > Action "Ajuster"

Actions :

  • Cliquer sur "Ajuster" pour l'article concerné
  • Choisir le type d'ajustement :
    • set : Définir le stock à une valeur exacte (recommandé pour inventaire)
    • add : Ajouter une quantité
    • remove : Retirer une quantité
  • Saisir la quantité physique réelle
  • Saisir la date d'inventaire
  • Cocher "Rapproché" pour indiquer que l'inventaire est validé
  • Saisir une référence (ex: INV-2025-001) et notes explicatives
Étape 4 : Validation et traçabilité

Résultat :

  • Le stock est ajusté automatiquement
  • Une fiche de stock de type "Inventaire" est créée
  • La date d'inventaire est enregistrée
  • Le champ "rapproché" est coché
  • L'écart est visible dans la fiche de stock

Règles CRITICAL - Inventaire

  • Irréversible : Un ajustement de stock ne peut pas être annulé, seulement corrigé par un nouvel ajustement
  • Type "set" recommandé : Utiliser toujours le type "Définir à" pour éviter les erreurs de calcul
  • Rapprochement obligatoire : Cocher "Rapproché" SEULEMENT après validation du responsable
  • Fréquence : Inventaire physique au moins 1 fois par an (recommandé : trimestriel pour articles de valeur)
  • Documentation : Toujours saisir une référence et notes explicatives pour audit

Exemple concret : Inventaire Robinets 1/2"

Situation :

  • Stock théorique : 150 pièces
  • Comptage physique : 142 pièces
  • Écart : -8 pièces (perte/casse non déclarée)

Action :

  • Type ajustement : "Définir à"
  • Quantité : 142
  • Date inventaire : 15/11/2025
  • Référence : INV-TANA-112025-001
  • Notes : "Inventaire trimestriel - Écart de 8 pièces probablement dû à casse non déclarée lors de livraisons terrain"
  • Rapproché : ✅ Coché

Workflow 2 : Fiche de Stock

La fiche de stock enregistre TOUS les mouvements d'un article dans un magasin : achats, livraisons, transferts, inventaires. Elle est alimentée automatiquement par les autres workflows.
flowchart LR A[Achat Réceptionné] -->|Entrée| E[Fiche de Stock] B[Livraison Terrain] -->|Sortie| E C[Transfert Entrant] -->|Entrée| E D[Transfert Sortant] -->|Sortie| E F[Inventaire] -->|Ajustement| E E --> G[Stock Cumulé] G --> H[Consultation & Analyse]

Types d'opérations enregistrées

Type Déclencheur Impact Stock Traçabilité
Achat Réception d'un achat (statut → Réceptionné) ➕ Entrée Référence achat, purchase_id
Livraison Retour ticket avec livraison=True ➖ Sortie Référence planning, ouvrage, employé
Transfert Entrée Réception transfert (statut → Reçu) ➕ Entrée N° transfert, magasin origine, transfert_id
Transfert Sortie Envoi transfert (statut → En cours) ➖ Sortie N° transfert, magasin destination, transfert_id
Inventaire Ajustement manuel suite inventaire ➕➖ Ajustement Référence INV, date inventaire, écart
Consulter une fiche de stock

Accès : Inventaire > Fiches de Stock

Filtres obligatoires :

  • Désignation : Article à consulter (ex: Robinet 1/2")
  • Magasin : Base de stockage (ex: Tana)

Filtres optionnels :

  • Date début / Date fin : Période à analyser

Informations affichées :

  • Date opération, Type, Référence
  • Ouvrage (si livraison), Employé
  • Entrée, Sortie, Stock cumulé
  • Pour inventaire : Inventaire physique, Écart
  • Stock actuel (dernier stock cumulé)
  • Dernier inventaire (date)

Règles CRITICAL - Fiche de Stock

  • Automatique : Les fiches sont créées automatiquement, NE PAS créer manuellement sauf inventaire
  • Suppression interdite : Ne supprimer une ligne QUE si erreur de saisie (impact sur stock cumulé)
  • Stock négatif = problème : Un stock cumulé négatif indique une sortie sans stock suffisant (alerte rouge)
  • Consultation obligatoire : Avant chaque inventaire, consulter la fiche pour identifier les mouvements
  • Traçabilité : Chaque ligne doit avoir une référence (achat, transfert, planning) pour audit

Exemple concret : Fiche Robinet 1/2" - Magasin Tana

Date Type Référence Entrée Sortie Stock
01/10/25 Inventaire INV-TANA-092025 - - 100
05/10/25 Achat A-2025-00123 50 - 150
10/10/25 Livraison PL-2025-00456 (Ouvrage: Ambanja BP) - 20 130
15/10/25 Transfert Sortie TRF-2025-005 → Diego - 30 100
20/10/25 Livraison PL-2025-00478 (Ouvrage: Nosy Be Ville) - 25 75

Stock actuel : 75 pièces | Dernier inventaire : 01/10/2025 (100 pièces)

Workflow 3 : Calcul des Commandes

Le calcul automatique des commandes analyse les demandes terrain récentes et le stock actuel pour déterminer les quantités à commander par base.
flowchart TD A[Début Calcul] --> B[Sélectionner Base] B --> C[Définir Période Analyse] C --> D[Récupérer Demandes Terrain] D --> E[Récupérer Stock Actuel] E --> F[Calculer Quantité à Commander] F --> G{Stock Suffisant?} G -->|Oui| H[Quantité = 0] G -->|Non| I[Quantité = Demande - Stock] H --> J[Afficher Résultats] I --> J J --> K[Créer Achat Fournisseur]
Étape 1 : Lancer le calcul

Accès : Inventaire > Calcul des Commandes

Paramètres :

  • Base/Magasin : Magasin à réapprovisionner
  • Nombre de jours : Période d'analyse (défaut : 30 jours)

Logique de calcul :

Quantité à commander = MAX(0, Quantité demandée - Stock actuel)
Étape 2 : Analyser les résultats

Informations affichées :

  • Désignation (article concerné)
  • Quantité demandée (somme des demandes terrain sur la période)
  • Stock actuel (disponible dans le magasin)
  • Stock réservé (déjà affecté à des plannings)
  • Quantité à commander (calculée automatiquement)
  • Nombre de lignes de planning concernées

Actions :

  • Trier par quantité à commander (descendant) pour prioriser
  • Identifier les articles en rupture (stock actuel = 0)
  • Ajuster manuellement les quantités selon budget disponible
Étape 3 : Créer l'achat fournisseur

Actions :

  • Exporter les résultats en Excel
  • Grouper les articles par fournisseur
  • Créer un achat pour chaque fournisseur (voir Workflow 4)
  • Relancer le calcul après livraison pour vérifier les besoins résiduels

Règles CRITICAL - Calcul des Commandes

  • Période adaptée : 30 jours = besoin mensuel moyen, 90 jours = tendance trimestrielle
  • Stock réservé : Prendre en compte le stock réservé (déjà affecté mais non livré)
  • Seuil de sécurité : Commander 10-20% de plus pour éviter les ruptures
  • Consolidation : Grouper les commandes par fournisseur pour réduire les frais de livraison
  • Fréquence : Relancer le calcul chaque semaine pour ajuster les besoins

Exemple concret : Calcul Commande Magasin Tana (30 derniers jours)

Désignation Demandé Stock Réservé À Commander
Robinet 1/2" 85 50 20 55 (85 - 30 disponible)
Tuyau PVC Ø 32mm 120 m 200 m 50 m 0 (stock suffisant)
Coude PVC 90° Ø 25mm 45 0 0 45 (RUPTURE)

⚠️ Action : Commander en priorité les Coudes PVC (rupture) et Robinets 1/2" (stock insuffisant)

Workflow 4 : Achat Fournisseur

Le workflow d'achat suit un processus strict en 6 étapes : Brouillon → Commandé → Livré → Réceptionné → Facturé → Payé. La réception génère automatiquement l'entrée en stock et l'export DiameX.
stateDiagram-v2 [*] --> Brouillon Brouillon --> Commandé : Validation commande Commandé --> Livré : Fournisseur livre Livré --> Réceptionné : Réception magasinier Réceptionné --> Facturé : Facture reçue Facturé --> Payé : Paiement effectué Brouillon --> Annulé : Annulation Commandé --> Annulé : Annulation Payé --> [*] Annulé --> [*] note right of Réceptionné Création automatique: - Entrée stock - Mouvement stock - DiameX Temporaire end note
Étape 1 : Créer un achat (Brouillon)

Accès : Inventaire > Achats > Nouvel Achat

Informations requises :

  • N° Achat : Généré automatiquement (ex: A-2025-00001)
  • Date d'achat : Date de création
  • Fournisseur : Sélection dans la liste
  • Magasin de destination : Où seront livrés les articles
  • Compte comptable : Compte d'imputation (ex: 601 - Achats)
  • Commandé par : Employé responsable

Ajouter les articles :

  • Rechercher la désignation
  • Saisir quantité et prix unitaire
  • Le montant total se calcule automatiquement
Étape 2 : Passer commande (Commandé)

Action : Modifier le statut de "Brouillon" à "Commandé"

Résultat :

  • Achat validé et envoyé au fournisseur
  • Date de commande enregistrée
  • Impossible de modifier les articles (sauf annulation)
Étape 3 : Livraison fournisseur (Livré)

Action : Modifier le statut à "Livré" quand le fournisseur livre

Informations :

  • Date de livraison réelle
  • Bon de livraison fournisseur (en notes)
Étape 4 : Réception magasinier (Réceptionné) - CRITICAL

Action : Cliquer sur "Réceptionner" dans Actions

⚙️ Le système effectue automatiquement :

  1. Pour chaque article de l'achat :
    • Mise à jour quantity_received = quantity_ordered
    • Création/Mise à jour du stock dans la base (table stocks)
    • Création d'un mouvement de stock type "Entrée" (table stock_movements)
    • stock.current_quantity += quantity_ordered
    • Création d'une fiche de stock type "Achat" (table fiches_stock)
  2. Création transaction DiameX Temporaire :
    • Description : NIF_Nom fournisseur_Nom désignation(s)_Montant Ar
    • Cat (compte_code) : Compte sélectionné dans l'achat
    • Out (montant_out) : Montant total de l'achat
    • Date_m : Date de réception
    • Prog/ACTIV : Volet de la base du magasin
    • Info : "Hydria Achats"
    • Statut : "en_attente" (en attente d'envoi vers DiameX)

⚠️ Cette action est IRRÉVERSIBLE - Le stock est définitivement augmenté

Étape 5 : Facturé et Payé

Facturé :

  • Saisir le numéro de facture fournisseur dans "Numéro DiameX"
  • Modifier le statut à "Facturé"

Payé :

  • Après paiement effectif au fournisseur
  • Modifier le statut à "Payé"
  • Cycle d'achat terminé

Règles CRITICAL - Achat

  • Réception = Irréversible : Une fois réceptionné, l'achat ne peut PAS être annulé (stock déjà augmenté)
  • Compte obligatoire : Le compte comptable DOIT être renseigné AVANT réception (sinon export DiameX échoue)
  • Magasin obligatoire : Le magasin DOIT être renseigné pour la réception
  • Vérifier quantités : Contrôler physiquement les quantités AVANT de cliquer "Réceptionner"
  • Export DiameX : Les lignes DiameX en "en_attente" doivent être exportées périodiquement vers le système comptable
  • Un achat = Un fournisseur : Ne pas mélanger plusieurs fournisseurs dans un même achat

Exemple concret : Achat Robinetterie chez SODIM

Création (Brouillon) :

  • N° Achat : A-2025-00234
  • Fournisseur : SODIM (NIF: 123456789)
  • Magasin : Tana
  • Compte : 601 - Achats stockés
  • Articles :
    • Robinet 1/2" : 50 pièces × 12,000 Ar = 600,000 Ar
    • Coude PVC 90° Ø 25mm : 100 pièces × 800 Ar = 80,000 Ar
  • Total : 680,000 Ar

Réception (15/11/2025) :

  • ✅ Entrée stock Robinet 1/2" : +50 pièces (50 → 100)
  • ✅ Entrée stock Coude PVC : +100 pièces (0 → 100)
  • ✅ 2 mouvements de stock créés
  • ✅ 2 fiches de stock créées
  • ✅ Transaction DiameX créée :
    • Description : "NIF_SODIM_Robinet 1/2", Coude PVC 90° Ø 25mm_680,000 Ar"
    • Cat : 601
    • Out : 680,000.00
    • Statut : en_attente

Workflow 5 : Transfert Entre Magasins

Le transfert permet de déplacer du stock entre deux magasins. Il suit un workflow en 4 statuts avec double validation : envoi par le magasin origine, réception par le magasin destination.
stateDiagram-v2 [*] --> EnAttente : Création transfert EnAttente --> EnCours : Envoi magasin origine EnCours --> Reçu : Réception magasin destination EnAttente --> Annulé : Annulation EnCours --> Annulé : Annulation Reçu --> [*] Annulé --> [*] note right of EnCours Sortie stock origine: - Stock diminué - Mouvement "Transfert Sortie" - Fiche stock créée end note note right of Reçu Entrée stock destination: - Stock augmenté - Mouvement "Transfert Entrée" - Fiche stock créée end note
Étape 1 : Créer le transfert (En attente)

Accès : Inventaire > Transferts > Nouveau Transfert

Informations requises :

  • N° Transfert : Généré automatiquement (ex: TRF-2025-00001)
  • Date de transfert : Date de création
  • Magasin d'origine : Magasin qui envoie le stock
  • Magasin de destination : Magasin qui reçoit le stock
  • Date d'arrivée prévue : Estimation (optionnel)
  • Initié par : Employé responsable

Ajouter les articles :

  • Rechercher la désignation
  • Saisir la quantité à transférer
  • Vérifier que le stock origine est suffisant
Étape 2 : Envoi depuis magasin origine (En cours)

Action : Cliquer sur "Démarrer Transfert" dans Actions

⚙️ Le système effectue automatiquement :

  • Pour chaque article du transfert :
    • Vérification du stock disponible dans magasin origine
    • Diminution du stock origine : stock.current_quantity -= quantity_sent
    • Création mouvement stock type "Transfert Sortie" (base origine)
    • Création fiche stock type "Transfert Sortie" (base origine)
    • Statut du transfert → "En cours"

⚠️ Le stock origine est définitivement diminué

Étape 3 : Réception magasin destination (Reçu)

Action : Cliquer sur "Réceptionner" dans Actions

⚙️ Le système effectue automatiquement :

  • Pour chaque article du transfert :
    • Saisie optionnelle de la quantité réellement reçue
    • Augmentation du stock destination : stock.current_quantity += quantity_received
    • Création mouvement stock type "Transfert Entrée" (base destination)
    • Création fiche stock type "Transfert Entrée" (base destination)
    • Enregistrement de l'employé réceptionnaire
    • Date de réception réelle enregistrée
    • Statut du transfert → "Reçu"

Gestion des écarts :

  • Si quantité reçue < quantité envoyée : Écart enregistré (perte en transit)
  • Ajustement manuel du stock origine si nécessaire (inventaire)

Règles CRITICAL - Transfert

  • Envoi = Sortie irréversible : Une fois "En cours", le stock origine est diminué définitivement
  • Vérifier stock avant envoi : Le système bloque si stock origine insuffisant
  • Double validation : Envoi PAR magasin origine + Réception PAR magasin destination
  • Traçabilité : Chaque transfert crée 2 fiches de stock (sortie origine + entrée destination)
  • Gestion des écarts : Si écart à la réception, créer un inventaire pour ajuster le stock origine
  • Annulation : Possible SEULEMENT si statut "En attente" (avant envoi)

Exemple concret : Transfert Tana → Diego (Robinet 1/2")

Création (01/11/2025) :

  • N° Transfert : TRF-2025-00012
  • Origine : Magasin Tana (Stock actuel : 100 pièces)
  • Destination : Magasin Diego (Stock actuel : 10 pièces)
  • Quantité : 30 pièces
  • Initié par : Jean RAKOTO

Envoi (02/11/2025) :

  • ✅ Stock Tana : 100 → 70 pièces (-30)
  • ✅ Mouvement "Transfert Sortie" créé (Tana)
  • ✅ Fiche stock "Transfert Sortie" créée (Tana)
  • Statut : En cours

Réception (05/11/2025) :

  • Quantité reçue : 29 pièces (1 pièce cassée en transit)
  • ✅ Stock Diego : 10 → 39 pièces (+29)
  • ✅ Mouvement "Transfert Entrée" créé (Diego)
  • ✅ Fiche stock "Transfert Entrée" créée (Diego)
  • Reçu par : Marie RANDRIA
  • Statut : Reçu
  • ⚠️ Écart : 1 pièce → Inventaire Tana à créer si stock théorique incorrect

FAQ - Questions Fréquentes

❓ Comment gérer un stock négatif dans la fiche de stock ?

Cause : Une sortie a été effectuée alors que le stock réel était insuffisant (erreur de saisie ou livraison non enregistrée).

Solution :

  1. Identifier la ligne qui a causé le stock négatif
  2. Vérifier s'il y a eu une entrée oubliée (achat, transfert)
  3. Si oui : Créer l'entrée manquante avec la date correcte
  4. Si non : Créer un ajustement d'inventaire pour corriger
  5. Ajouter une note explicative pour audit
❓ Quelle différence entre "Stock actuel" et "Stock disponible" ?
  • Stock actuel (current_quantity) : Quantité physique totale présente dans le magasin
  • Stock réservé (reserved_quantity) : Quantité déjà affectée à des plannings mais pas encore livrée
  • Stock disponible (available_quantity) : Stock actuel - Stock réservé (peut être utilisé pour de nouvelles demandes)

Exemple : Stock actuel = 100, Réservé = 30 → Disponible = 70

❓ Que faire si un achat réceptionné contient des articles défectueux ?

Workflow de retour fournisseur :

  1. NE PAS annuler la réception (stock déjà augmenté)
  2. Créer un nouvel achat de type "Retour" avec quantité négative
  3. OU créer un ajustement de stock de type "Perte" avec référence "Retour fournisseur"
  4. Contacter le fournisseur pour avoir ou remplacement
  5. Enregistrer la nouvelle livraison comme un achat séparé
❓ Comment exporter les lignes DiameX Temporaire vers le système comptable ?

Méthode actuelle :

  1. Accéder à : Comptabilité > DiameX Temporaire
  2. Filtrer par statut "en_attente"
  3. Exporter en Excel
  4. Importer le fichier Excel dans DiameX
  5. Marquer les lignes comme "exporté" dans Hydria

⚠️ Amélioration future : Script automatique d'export direct vers DiameX (à développer)

❓ Quelle fréquence pour les inventaires physiques ?

Recommandations selon le type d'article :

  • Articles de valeur élevée (robinets, compteurs) : Inventaire trimestriel
  • Consommables courants (tuyaux, coudes) : Inventaire semestriel
  • Fournitures administratives : Inventaire annuel
  • Inventaire complet obligatoire : Au moins 1 fois par an (fin d'année fiscale)

💡 Astuce : Planifier les inventaires en période creuse d'activité terrain

❓ Puis-je modifier un achat après réception ?

NON - Une fois réceptionné, un achat ne peut plus être modifié car :

  • Le stock a déjà été augmenté
  • Les mouvements de stock ont été créés
  • Une transaction DiameX a été générée

Si erreur détectée après réception :

  1. Créer un ajustement d'inventaire pour corriger le stock
  2. Ajouter une note explicative dans l'achat
  3. Créer un nouvel achat correctif si nécessaire
