Points clés du workflow forfaitaire

  • Détection automatique : Les factures impayées sont détectées automatiquement (numeroDiameX NULL)
  • Affichage systématique : L'historique des impayés apparaît dans chaque nouvelle facture
  • Total cumulé : Le montant à payer inclut la facture actuelle + tous les impayés antérieurs
  • Impression bloquante : Une fois imprimée (facture_imprimee=True), la facture ne peut plus être recalculée

Relations clés & Règles métier

Chaîne géographique complète

Ouvrage → PointEau → Parcelle → Village → Fokontany → Commune → District → Région
Pour obtenir la commune d'un ouvrage, il faut suivre cette chaîne complète via les relations Django.

Règles Timezone (CRITICAL)

Timezone projet : Indian/Antananarivo (Madagascar, UTC+3)
Stockage BDD : UTC (ex: 2025-01-01 00:00 Madagascar = 2024-12-31 21:00 UTC)
Import dates : Utiliser tz_madagascar.localize(date_naive) (PAS make_aware)
Affichage dates : Convertir avec .astimezone(tz_madagascar) avant .date()
Filtres par date : Filtrer en Python APRÈS conversion timezone (JAMAIS en SQL)
JavaScript : Parser manuellement "YYYY-MM-DD" avec split() (PAS new Date(string))
