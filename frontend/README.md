# Hydria Frontend - Interface Web

## Configuration
Interface utilisateur moderne avec Tailwind CSS et DaisyUI pour l'application Hydria.

## Commandes
```bash
# Installer dépendances
npm install

# Build CSS
npm run build

# Watch mode pour développement
npm run dev
```

## Technologies
- Tailwind CSS
- DaisyUI
- PostCSS
- Autoprefixer
