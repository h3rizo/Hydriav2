Trois règles qui évitent les pièges habituels
1 Les cibles ne grandissent pas avec l'écran : 64 dp reste 64 dp. C'est la quantité d'information visible qui augmente, pas la taille des boutons.
2 Aucun contenu ne s'étire au-delà de 720 dp de large : les volets ont des largeurs fixes (340 / 392 / 400 dp) et c'est le volet de détail qui absorbe le reste.
3 Rien n'est exclusif à la tablette côté métier : le traitement par lot est un raccourci, jamais le seul chemin. Un agent sur téléphone doit pouvoir tout faire.
